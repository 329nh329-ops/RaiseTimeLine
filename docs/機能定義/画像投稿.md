# 機能定義：画像投稿

[機能一覧.md](../機能一覧.md) のNo.8に対応する詳細定義。

## 1. 概要
投稿作成時、およびプロフィールアイコン設定時に画像を添付し、AWS S3に保存する機能。

## 2. 対象範囲
- 投稿への画像添付（[投稿.md](./投稿.md) 参照）
- プロフィールアイコン画像（[プロフィール.md](./プロフィール.md) 参照）

## 3. 入力仕様

| 項目 | 内容 |
|---|---|
| 対応形式 | JPEG, PNG（実装時に必要に応じて追加検討） |
| 最大枚数（投稿） | 1枚 |
| 最大ファイルサイズ | 実装時に決定（例：5MB程度を上限とする） |

## 4. 処理仕様
- フロントエンドから画像ファイルを送信し、バックエンドAPI経由でAWS S3にアップロードする
- アップロード成功後、S3上の画像URL（またはオブジェクトキー）をデータベースに保存し、投稿・プロフィールの表示時にそのURLを参照する
- アップロード失敗時（サイズ超過・形式不正等）はエラーメッセージを表示し、投稿・保存を中止する
- S3バケットへの直接的な公開アクセス可否、署名付きURLの利用有無等の詳細は実装時に検討する

## 5. 削除との関係
- 投稿が削除された場合、S3上の対応する画像ファイルも削除するかどうかは実装時に検討する（データベース上の参照は投稿削除に伴い削除される）

## 6. 対象外
- 複数枚の画像添付（1投稿につき1枚のみ）
- 動画の投稿
- 画像の加工・フィルター機能
