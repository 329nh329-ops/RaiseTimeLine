# 機能定義：タイムライン

[機能一覧.md](../機能一覧.md) のNo.2に対応する詳細定義。

## 1. 概要
ログイン中のユーザーが投稿を閲覧するための一覧画面。「全体タイムライン」と「フォロー中タイムライン」の2種類をタブで切り替える。

## 2. 表示内容

### 2.1 全体タイムライン
- 全ユーザーの投稿を、投稿日時の新しい順に一覧表示する
- 自分自身の投稿も含めて表示する

### 2.2 フォロー中タイムライン
- 自分がフォローしているユーザーの投稿のみを、投稿日時の新しい順に一覧表示する
- 自分自身の投稿は含めない（フォロー中ユーザーの投稿のみとする）
- フォローしているユーザーが1人もいない場合は「フォロー中のユーザーがいません」等のメッセージを表示する

## 3. 投稿1件あたりの表示要素
- 投稿者のアイコン・ユーザー名（クリックでプロフィール画面へ遷移）
- 投稿本文（テキスト）
- 添付画像（ある場合のみ）
- 投稿日時
- コメント数
- いいね数、いいね済みかどうかの状態（いいね済みの場合はアイコンの見た目を変える）
- いいねボタン、コメント遷移導線
- 自分の投稿の場合のみ、編集・削除の操作を表示する

## 4. 操作

| 操作 | 内容 |
|---|---|
| タブ切り替え | 「全体」「フォロー中」タブをクリックして表示対象を切り替える |
| 投稿作成 | タイムライン上部の投稿フォームからテキスト（＋画像）を投稿する（詳細は[投稿.md](./投稿.md)） |
| いいね | 各投稿のいいねボタンを押す（詳細は[いいね.md](./いいね.md)） |
| コメントへの遷移 | 投稿をクリックすると投稿詳細（コメント一覧）画面に遷移する（詳細は[コメント.md](./コメント.md)） |
| プロフィールへの遷移 | 投稿者のユーザー名・アイコンをクリックするとそのユーザーのプロフィール画面に遷移する（詳細は[プロフィール.md](./プロフィール.md)） |
| 投稿の編集・削除 | 自分の投稿にのみ表示される操作から行う（詳細は[投稿.md](./投稿.md)） |

## 5. 一覧取得の方針
- ページネーション方式（件数）は実装時に決定するが、最低限「新着順」であることは必須要件とする
- 投稿の取得件数が多くなる場合はページング（もしくは無限スクロール）を検討する。詳細な方式は実装時のIssueで決定する

## 6. 対象外
- 「おすすめ」等のアルゴリズムタイムライン
- インプレッション数の表示
- リツイートの表示
