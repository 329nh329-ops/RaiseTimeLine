# 機能定義：検索

[機能一覧.md](../機能一覧.md) のNo.9に対応する詳細定義。

## 1. 概要
投稿本文のキーワード検索と、ユーザー名によるユーザー検索の2種類を提供する。

## 2. 対象とする検索

### 2.1 キーワード検索（投稿検索）
- 入力したキーワードが本文に含まれる投稿を、新着順で一覧表示する
- 部分一致検索とする（前方一致・完全一致に限定しない）
- 検索結果の各投稿は、タイムラインと同様の表示要素（投稿者・本文・画像・いいね数・コメント数）を持つ

### 2.2 ユーザー検索
- 入力した文字列がユーザー名に部分一致するユーザーを一覧表示する
- 検索結果の各ユーザーはアイコン・ユーザー名を表示し、クリックでプロフィール画面に遷移する

## 3. 画面構成
- 検索画面に検索ボックスを1つ配置し、「投稿」「ユーザー」の2タブで結果を切り替える（もしくは同一画面に2セクションを並べる。詳細は画面設計で決定）

## 4. 入力仕様

| 項目 | 必須/任意 | 制約 |
|---|---|---|
| 検索キーワード | 必須（未入力での検索は行わない） | 文字列 |

- 検索キーワードが空の状態では検索を実行しない（ボタン非活性、またはエラー表示）
- 該当件数が0件の場合は「該当する投稿（ユーザー）がありません」等のメッセージを表示する

## 5. 対象外
- ハッシュタグ検索
- 検索履歴・保存検索
- 高度な検索演算子（AND/OR、期間指定等）
