# 機能定義：いいね

[機能一覧.md](../機能一覧.md) のNo.7に対応する詳細定義。

## 1. 概要
投稿およびコメントに対して行う「いいね」機能。投稿者・コメント者本人以外の第三者もいいねできる。

## 2. 対象
- 投稿へのいいね
- コメントへのいいね

いずれも同じ仕様（誰でもいいね可能、二重いいね不可、件数表示）とする。

## 3. 操作
- 対象（投稿またはコメント）のいいねボタンを押すと、いいね状態になり、件数が1増える
- 既にいいね済みの状態で同じボタンを押すと、いいねが取り消され、件数が1減る（トグル動作）
- 自分自身の投稿・コメントに対しても、自分でいいねすることができる

## 4. 制約
- 同一ユーザーが同一の投稿（またはコメント）に対して二重にいいねできない（1ユーザー×1対象につき、いいねは高々1件）
- 未ログイン状態ではいいね操作を行えない

## 5. 表示
- 投稿・コメントそれぞれに、いいねの合計件数を表示する
- ログイン中ユーザーが既にいいね済みかどうかを、ボタンの見た目（色・アイコンの塗りつぶし等）で区別する

## 6. データ削除との関係
- 投稿が削除された場合、その投稿へのいいねも合わせて削除する
- コメントが削除された場合、そのコメントへのいいねも合わせて削除する

## 7. 対象外
- いいねしたユーザー一覧の表示
- いいね時の通知

## 8. 関連機能
- [投稿.md](./投稿.md)、[コメント.md](./コメント.md)：いいねの対象
