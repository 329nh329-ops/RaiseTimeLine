# 機能定義：プロフィール

[機能一覧.md](../機能一覧.md) のNo.4に対応する詳細定義。

## 1. 概要
各ユーザーの情報と投稿一覧を表示する画面。自分自身のプロフィールの場合のみ、編集操作および投稿の編集・削除操作を行える。

## 2. 表示内容（共通：自分・他ユーザーとも）
- アイコン画像
- ユーザー名
- 自己紹介文
- フォロー中の人数、フォロワーの人数
- そのユーザーの投稿一覧（新着順）
- 各投稿にはタイムラインと同様、いいね数・コメント数を表示する

## 3. 他ユーザーのプロフィールを見た場合
- フォロー／フォロー解除ボタンを表示する（詳細は[フォロー.md](./フォロー.md)）
- 投稿の編集・削除操作は表示しない

## 4. 自分のプロフィールを見た場合
- フォローボタンは表示しない（自分自身はフォローできない）
- 「プロフィールを編集」ボタンを表示する
- 自分の投稿一覧の各投稿に、編集・削除の操作を表示する（詳細は[投稿.md](./投稿.md)）

## 5. プロフィール編集

### 5.1 編集可能項目
| 項目 | 必須/任意 | 型・制約 | 備考 |
|---|---|---|---|
| ユーザー名 | 必須 | 文字列、1〜30文字程度 | |
| 自己紹介文 | 任意 | 文字列、160文字程度まで | |
| アイコン画像 | 任意 | 画像ファイル | AWS S3に保存する。未設定時はデフォルトアイコンを表示する |

### 5.2 処理仕様
- 「プロフィールを編集」から編集フォームを開き、上記項目を変更して保存する
- ユーザー名を空にして保存しようとした場合はエラーメッセージを表示し保存しない
- 保存後はプロフィール画面に反映される

## 6. 対象外
- メールアドレスの変更
- パスワードの変更
- フォロー中ユーザー一覧・フォロワー一覧の詳細表示（件数表示のみ）
- 非公開（鍵）アカウント設定
