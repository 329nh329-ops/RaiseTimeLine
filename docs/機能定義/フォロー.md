# 機能定義：フォロー

[機能一覧.md](../機能一覧.md) のNo.3に対応する詳細定義。

## 1. 概要
あるユーザーが別のユーザーをフォローする機能。一方向の関係であり、フォローされる側の承認は不要（申請制ではない）。

## 2. 操作
- フォローする：プロフィール画面の「フォロー」ボタンを押すと、対象ユーザーをフォローする
- フォロー解除する：フォロー中の状態で同じボタン（表示は「フォロー中」等に変わる）を押すと、フォローを解除する
- 自分自身をフォローすることはできない（自分のプロフィール画面にはフォローボタンを表示しない）

## 3. 入口（導線）
- 投稿者名／コメント者名・アイコンのクリックからプロフィール画面に遷移し、そこでフォロー操作を行う（プロフィール画面以外にフォローボタンは配置しない）
- 検索結果のユーザー一覧からプロフィール画面に遷移する導線も同様

## 4. データ・状態
- フォロー関係は「フォローする人（follower）」と「フォローされる人（following）」の組み合わせで一意に管理する
- 同じ相手に対して重複してフォロー関係を作らない（既にフォロー済みの場合はボタン押下でフォロー解除の確認とする）

## 5. 表示
- プロフィール画面に「フォロー中」の人数、「フォロワー」の人数を表示する
- 人数表示をクリックすると、フォロー中ユーザー一覧／フォロワー一覧画面に遷移し、対象ユーザーの一覧（アイコン・ユーザー名）を確認できる。一覧の各ユーザーをクリックすると、そのユーザーのプロフィール画面に遷移する
- フォロー中ユーザー一覧・フォロワー一覧は、自分のプロフィールだけでなく他ユーザーのプロフィールからも参照できる
- フォロー状態に応じてボタンの表示を「フォローする」／「フォロー中」で切り替える

## 6. フォロー中タイムラインへの反映
- フォロー・フォロー解除の操作結果は、即座に（もしくは次回のタイムライン取得時に）フォロー中タイムラインの表示内容に反映される（詳細は[タイムライン.md](./タイムライン.md)）

## 7. 対象外
- フォロー申請・承認制（鍵アカウント）
- フォロー時の通知
